Permissions and server settings

Only explicitly allowed features are available to guests. Playback, leaving, and the browser’s enable-playback prompt are mandatory. Pause, seek, skip, queue, casting, downloads, and account/library access cannot be granted here.

This is the actual guest renderer with the installed Jellyfin styles, branding CSS, and enabled declarative plugin controls. The live sample is generated in a sandbox: it uses no account, guest seat, or library media. CSS themes apply; arbitrary authenticated player scripts do not run.
